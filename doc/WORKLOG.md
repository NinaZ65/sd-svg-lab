## 2026-10-14 — 第一阶段基础框架与项目约束建立

### 目标

建立 SVG 命令行编辑器的 TypeScript / Node.js 基础框架，并在后续功能开发前明确项目级设计约束。

### 实现内容

- 添加最小命令行入口和读取—执行循环。
- 建立命令对象抽象及基于注册表的命令分发层。
- 添加文档和画布模型的基础结构。
- 建立以分组为基础的组合模型及历史管理边界。

本轮刻意保持结构精简、采用面向对象设计，尚未实现全部 SVG 功能，以建立清晰、可扩展的第一阶段基础。

主要架构选择为：

- 面向对象的命令层。

- 以分组为基础的组合模式。
- 明确的控制台输入输出边界。

### 人工智能建议与人工判断

## 2026-10-20 — 最终审计、失败测试与命令状态安全修复

### 发现与先行失败证据

接手时 `HEAD/main/origin/main/final` 均指向 `5d7ab2a`，工作区干净。最初只读审计发现两项真实缺陷，随后先加入测试、构建并执行：

```bash
npm run build
node --test dist/test/group-state.test.js dist/test/set-history.test.js
```

未修复实现的结果为 9 项中 7 失败、2 通过。关键失败证据：

- `group bad r1 missing` 已输出错误，但 `r1` 被摘进未挂接的 `bad`，原父节点、同级顺序、结构树及 SVG 不再相同；测试还检查 `r2`、`bad` 不存在及历史深度。
- `set r1 x 5 → undo → redo` 第一次重做后得到 0 而非 5；独立连续属性设置的历史及反复撤销/重做也失败。
- 分组跨父节点、非顺序选择后撤销，部分同级节点恢复位置不正确；祖先/后代及重复目标场景也暴露了边检查边修改的问题。

### 定位与修复

- `GroupCommand` 原先在遍历目标时即调用 `removeChild`。现先确认新标识符、全部目标、原父节点及同级位置、重复目标、非法祖先/后代关系；全部通过才修改。撤销按各父节点原同级位置升序恢复，重做复用稳定目标记录，不采用失败后回滚。
- `SetCommand` 原属性写入函数同时更新 `oldValue/nextValue`，撤销会覆盖重做所需值。现先确定属性写入操作，固定捕获 `previousValue/nextValue`，撤销/重做仅写值；支持恢复未设置的可选样式，并在写入前拒绝非法数值。
- 失败测试与对应修复合并为通过测试的逻辑提交，没有为了保留失败状态而提交破坏 `npm test` 的版本。上述先行运行结果在此如实记录。

### 相似命令的定向复查

检查移动、缩放、删除、创建、分组、解组、移入容器、置前及置后的闭包载荷、原父节点、原同级位置及失败后状态。新增 `command-history.test.ts`，先运行时 16 项中 6 失败、10 通过：

- 移入容器命令在同父节点移动后，重做未先移除旧位置，产生重复引用；同时未拒绝移入自身、后代或移动根节点的非法结构。现完整预验证后移动，重做始终先从活动父节点摘除。
- 解组命令原先把子节点追加到父节点末尾，且把根级容器误判为可解散。现按原 `groupIndex` 插入子节点，重做使用相同操作；执行前拒绝根级容器。
- 移动、缩放、删除、创建、置前及置后的本轮重复撤销/重做场景未发现同类载荷覆盖，没有为防范假设风险而改写这些结构操作。分组的多父节点恢复也由测试保护。

### 最小架构一致性修正

- `Document.createShape()` 委托 `ShapeFactory.fromSvg()`，SVG 参数转换与命令行创建复用工厂的类型到具体类映射，移除文档模型的第二套创建分派。
- 六种内置图形的嵌套序列化往返测试先发现线段端点读回为 0；定位到原属性名正则不接受数字，随后仅修正该正则，确保 `x1/y1/x2/y2` 被读到。未知标签及缺省样式行为继续测试。
- `Shape` 增加多态移动/缩放，分组负责递归，叶子负责自身几何；移动和缩放命令不再导入或判断具体类型。`captureGeometry()` 保存目标子树的局部几何恢复闭包，避免反向浮点运算导致精度漂移，不复制完整文档。
- 新增组合模式测试涵盖全部叶子类型、嵌套及空分组、无关同级节点，以及 10 轮精确撤销/重做。不扩展为插件框架、通用属性系统或序列化重构。
